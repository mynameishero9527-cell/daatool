# A股量化工具

集行情看板、个股K线分析、宏观情报、大宗商品监控、全球指数、机构评级与个股推荐于一体的本地量化分析工具。

依据《需求文档.md》《产品优化文档.md》及《需求优化文档2.0～12.0.md》实现。已交付口径见 **《需求优化文档12.0.md》**（策略引擎仍为设计未跑数）。下一版研究闭环（信号任务 / 跟踪 / 日 K 回放）见 **《需求优化文档13.0.md》**。

## 功能总览

| 模块 | 说明 |
|------|------|
| 行情看板 | 指数、涨跌统计、分时、情绪/周期/恐慌/攻守、明日概率；大盘/自选二级；买卖点分列提醒、自选股、黄历 |
| 个股分析 | 搜索 + 多周期K线 + v9 综合评分（技术/资金/基本面/行业消息）+ 购买指数/暗盘/企稳 + 涨跌归因与利空风险 |
| 个股筛选 | 多条件组合 + 语义规则/自然语言解析 + **财报评级 A/B/C/D** |
| 板块资金 | 行业/概念热力图、成分股、板块推荐；**板块资金分析**横向直方图（当天～3个月交易日） |
| 榜单 | 本地异动榜（涨跌停/换手/振幅/量比/主力等），含财报列 |
| 宏观情报 | 快讯/政策/日历/展望/板块事件/常识/公告；北京日筛选；无板块不回退指数权重 |
| 大宗商品 / 全球指数 | 商品行情与K线、全球指数、ETF、各国汇率（欧洲央行日线+即时价） |
| 个股推荐 | 多维榜单（含企稳/妖股/板块强弱），购买指数参与综合排序 |
| AI | 大盘/个股/选股/右键分析，未配置走本地规则 |
| 设置 | 数据源、缓存、同步、K线校验、财报评级重建、板块资金落库天数、任务开关与频率 |

## 技术架构

- **后端**：Python 3.10+ / FastAPI / APScheduler / httpx（连接池 + gzip）
- **存储**：SQLite（WAL 模式）+ 进程内 TTL 缓存（先写库后刷缓存）
- **数据源**：腾讯财经（P0）→ 新浪财经（P1）→ 离线兜底（P2），带健康度统计与熔断切换
- **前端**：原生 HTML/CSS/JS + ECharts（本地化，无外网依赖），深色金融主题，平铺选项卡，全异步刷新

## 快速开始

```bash
pip install -r requirements.txt
python run.py
# 浏览器访问 http://127.0.0.1:8888
```

首次启动会自动在后台执行全市场股票同步（约 10 秒），完成后看板统计与推荐榜单即有数据。

### Windows 一键脚本

| 脚本 | 作用 |
|------|------|
| `start.bat` | 一键启动：首次自动在项目内建 `.venv` 并安装依赖，生成启动报告，启动服务并打开浏览器；服务已在运行则直接打开页面 |
| `update.bat` | 更新：需先关闭服务。备份数据库 → `git pull --ff-only` → 重装依赖，过程写入 `data\logs\update.log` |
| `check_logs.bat [天数]` | 统计最近 N 天（默认 7）的 WARNING/ERROR/Traceback，检查服务状态，生成报告并用记事本打开 |

需要 Python 3.10+：建议安装到非 C 盘并勾选加入 PATH，或把完整版 Python 目录放到项目内 `runtime\python\`（脚本优先使用）。端口默认 8888，可先 `set QUANT_PORT=8889` 再运行脚本。

运行期文件全部在项目目录内，不写 C 盘用户目录：

| 路径 | 内容 |
|------|------|
| `.venv\` | Python 虚拟环境与依赖 |
| `data\quant.db` | 数据库（行情、指标、以及数据源/AI/策略等全部配置） |
| `data\logs\` | `app.log` 全部日志、`error.log` 警告及以上、`launcher.log` 启动器记录、`update.log` 更新记录（10MB 轮转） |
| `data\reports\` | `startup_*.txt` 启动报告、`log_report_*.txt` 异常日志报告，各保留 30 份，`*_latest.txt` 为最新一份 |
| `data\backup\` | 更新前的数据库备份，保留 10 份 |
| `data\cache\`、`data\tmp\` | pip 下载缓存、pyc 缓存、临时文件 |

## 目录结构

```
app/
├── config.py           # 全局配置（TTL、调度间隔、默认自选）
├── database.py         # SQLite 建表与读写
├── cache.py            # TTL 缓存中间件
├── scheduler.py        # 定时任务（盘前/盘中高中频/快讯/盘后/维护）
├── api.py              # FastAPI 路由
├── main.py             # 启动自检入口
├── datasources/        # 腾讯、新浪、离线兜底 + 熔断故障切换
└── services/           # 行情、K线、股票列表、宏观、商品、全球指数、评分、推荐
static/                 # 前端单页应用（含本地 ECharts）
scripts/                # bat 公共环境 env.bat、启动报告、异常日志报告、数据库备份
start.bat / update.bat / check_logs.bat
```

## 说明

- 机构评级为基于个股真实指标的规则化模拟数据，界面已标注「模拟·仅供参考」。
- 事件日历为常规发布时间预估（CPI/LPR/FOMC/非农/财报季等）。
- 本工具仅供学习研究，不构成任何投资建议。

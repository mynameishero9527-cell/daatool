# A股量化工具

集行情看板、个股K线分析、宏观情报、大宗商品监控、全球指数、机构评级与个股推荐于一体的本地量化分析工具。

依据《需求文档.md》与《产品优化文档.md》实现。

## 功能总览

| 模块 | 说明 |
|------|------|
| 行情看板 | A股核心指数、涨跌家数统计、领涨领跌、自选股列表，交易时段自动刷新 |
| 个股分析 | 全市场搜索（支持 300432 等全板块代码）、分时/日K/周K/月K + MA/MACD、综合评分、量能描述、增持/减持/保持提示、机构评级汇总 |
| 宏观情报 | 实时快讯（新浪7x24）+ 影响程度评估、未来1-3个月事件日历、政策追踪、重大事件专题 |
| 大宗商品 | 原油/金银铜等有色金属/能源/化工农产品实时价格，分类多选、关注置顶 |
| 全球指数 | 分区域展示（标注国家）+ 国内大A指数 + ETF 专区 |
| 个股推荐 | 全市场约 4600 只股票同步到本地库后多维分析：机构买入最多、散户买入最多、卖出最多、强势突破、超跌反弹、综合推荐、活跃成交 |
| 设置 | 数据源健康与启停、缓存状态与清理、全量同步、定时任务面板 |

## 技术架构

- **后端**：Python 3.10+ / FastAPI / APScheduler / httpx（连接池 + gzip）
- **存储**：SQLite（WAL 模式）+ 进程内 TTL 缓存（先写库后刷缓存）
- **数据源**：腾讯财经（P0）→ 新浪财经（P1）→ 离线兜底（P2），带健康度统计与熔断切换
- **前端**：原生 HTML/CSS/JS + ECharts（本地化，无外网依赖），深色金融主题，平铺选项卡，全异步刷新

## 快速开始

```bash
pip install -r requirements.txt
python run.py
# 浏览器访问 http://127.0.0.1:8000
```

首次启动会自动在后台执行全市场股票同步（约 10 秒），完成后看板统计与推荐榜单即有数据。

## 目录结构

```
app/
├── config.py           # 全局配置（TTL、调度间隔、默认自选）
├── database.py         # SQLite 建表与读写
├── cache.py            # TTL 缓存中间件
├── scheduler.py        # 定时任务（盘前/盘中高中频/快讯/盘后/维护）
├── api.py              # FastAPI 路由
├── main.py             # 启动自检入口
├── datasources/        # 腾讯、新浪、离线兜底 + 熔断故障切换
└── services/           # 行情、K线、股票列表、宏观、商品、全球指数、评分、推荐
static/                 # 前端单页应用（含本地 ECharts）
```

## 说明

- 机构评级为基于个股真实指标的规则化模拟数据，界面已标注「模拟·仅供参考」。
- 事件日历为常规发布时间预估（CPI/LPR/FOMC/非农/财报季等）。
- 本工具仅供学习研究，不构成任何投资建议。
